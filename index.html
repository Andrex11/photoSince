Privacidad y Seguridad Garantizada

Las fotografías se procesan localmente en tu navegador y no se envían a nuestros servidores ni a ningún servicio externo.

¿Cómo funciona?

  • Procesamiento en memoria del cliente: La imagen se decodifica y se manipula exclusivamente mediante la API Canvas de HTML5 en la memoria RAM de tu propio navegador.
  • Sin subidas ni almacenamiento externo: No se realizan peticiones HTTP con los archivos ni se conecta a ninguna base de datos o servidor.
  • Sin telemetría invasiva: No rastreamos tus fotografías ni recopilamos metadatos personales.
  • Liberación de recursos: Cuando cambias de imagen o cierras la pestaña, los objetos creados en memoria se liberan de inmediato.

Nota sobre privacidad: El pixelado altera irreversiblemente los píxeles seleccionados para ocultar los rasgos faciales. Para máxima seguridad, utiliza la intensidad "Intenso" para evitar que algoritmos de reconstrucción puedan deducir características del rostro.
